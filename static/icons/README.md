# PWA Icons

These icon files are referenced by `static/manifest.webmanifest` and must be replaced with real artwork before launch.

Required files:

| File | Size | Notes |
|------|------|-------|
| `icon-192.png` | 192x192 | Maskable; safe zone is the inner 66% |
| `icon-512.png` | 512x512 | Maskable; safe zone is the inner 66% |

The icon should use the coral (`#e8604c`) brand color on a white or transparent background.

Until real icons are provided, browsers will fall back gracefully — the PWA will still install but will use a generic icon.
